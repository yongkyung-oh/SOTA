# Position: State-of-the-Art Claims Require State-of-the-Art Evidence

This repository contains the ongoing implementation and analysis code for our ICML 2026 position paper on the evaluation and reporting of state-of-the-art (SOTA) claims in machine learning.

Paper: [arXiv:2605.17273](https://arxiv.org/abs/2605.17273?utm_source=chatgpt.com)

The project is currently under active development. Code, benchmark protocols, and analysis scripts will be updated progressively.
